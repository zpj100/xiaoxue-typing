# 版本管理

编译号只来自两处，必须一起改：

| 位置 | 字段 |
|------|------|
| `VERSION` | 第一行版本名，第二行 versionCode |
| `src/lib/version.ts` | `APP_VERSION` / `APP_VERSION_CODE` |
| `package.json` | `version` |
| `android/app/build.gradle` | `versionName` / `versionCode` |

禁止只改 README。APK 不进 Git，只作为 GitHub Release 附件。

## 公开仓

- 源码：https://github.com/zpj100/xiaoxue-typing
- 发行版：https://github.com/zpj100/xiaoxue-typing/releases
- 关于页检查：`https://api.github.com/repos/zpj100/xiaoxue-typing/releases/latest`

## 发版步骤

1. 四个版本号一起改
2. `npm run android:assets`（产出 `dist/`，Gradle 直接打进 APK）
3. `cd android && ./gradlew assembleRelease --no-daemon`
4. 拷贝 `android/app/build/outputs/apk/release/app-release.apk` 为 `xiaoxue-typing-{version}.apk`
5. `git tag v{version}` 并 push
6. GitHub Release 上传该 APK

关于页「检查更新」读 latest Release；发现更高版本后点「从发行版更新」下载 APK 并唤起系统安装器。
