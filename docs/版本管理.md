# 版本管理

四个位置必须一起改：

| 位置 | 字段 |
|------|------|
| `VERSION` | 第一行版本名，第二行 versionCode |
| `src/lib/version.ts` | `APP_VERSION` / `APP_VERSION_CODE` |
| `package.json` | `version` |
| `android/app/build.gradle` | `versionName` / `versionCode` |

禁止只改 README。APK 不进 Git，只作为 Gitee Release 附件。

## 公开仓

- Gitee 源码：https://gitee.com/zpj100/xiaoxue-typing
- Gitee 发行版：https://gitee.com/zpj100/xiaoxue-typing/releases
- 关于页检查：`https://gitee.com/api/v5/repos/zpj100/xiaoxue-typing/releases/latest`
- GitHub 镜像：https://github.com/zpj100/xiaoxue-typing

## 发版步骤

1. 四个版本号一起改
2. `npm run android:assets`
3. `cd android && ./gradlew assembleRelease --no-daemon`
4. 拷贝 `android/app/build/outputs/apk/release/app-release.apk` 为 `xueji-xiaoxue-{version}.apk`
5. `git tag v{version}` 并 push Gitee / GitHub
6. Gitee Release 上传该 APK

关于页「检查更新」读 Gitee latest Release；发现更高版本后点「从发行版更新」下载 APK 并唤起系统安装器。
